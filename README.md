# 統計検定2級 学習アプリ

統計検定2級の取得を目指すための学習・試験対策Webアプリです。  
全11単元・150問以上で試験範囲を完全網羅しています。

🔗 **公開URL**: https://korosk.github.io/toukei-2kyuu-app/

---

## 機能

### 📚 学習モード
- 全11単元のテキスト解説
- KaTeX による数式レンダリング
- 統計表・図・重要ポイント付き
- 単元別確認テスト（ランダム出題）
- 学習進捗の記録

### 📝 試験モード（CBT形式）
- 本番を想定した35問・90分のタイマー付き試験
- 問題フラグ機能（後で見直し）
- 問題ナビゲーションパネル
- 内蔵電卓（本番試験と同様）
- 採点後に全問解説・単元別正解率を表示

### 📈 進捗管理
- 単元別の学習進捗・正解率
- 受験履歴（スコア・所要時間）
- localStorage によるデータ永続化

| 単元 | 内容 |
|------|------|

| 7 | 統計的仮説検定 |
| 8 | 分散分析（ANOVA） |
| 9 | 回帰分析・相関分析 |
| 10 | ノンパラメトリック検定 |
| 11 | 時系列分析の基礎 |
