# 統計検定2級 学習アプリ

統計検定2級の取得を目指すための学習・試験対策 Web アプリです。  
全 11 単元・115 問で試験範囲を完全網羅。**数学が苦手な方でも理解できる**「例題先・式は後から」方式の解説を採用しています。

🔗 **公開 URL**: https://korosk.github.io/toukei-2kyuu-app/

---

## 主な機能

### 📚 学習モード
- 全 11 単元のテキスト解説（数学が苦手でも分かる「例題先」方式）
- KaTeX による数式レンダリング（式の読み方も丁寧に解説）
- 単元別確認テスト（選択肢・出題順ともにランダム）
- 学習進捗・正解率の記録
- **フォーカスモード**：右下の ⛶ ボタンでヘッダーを非表示にして集中学習

### 📝 試験モード（CBT 形式）
- 本番準拠：35 問・90 分タイマー（残り 5 分で赤色警告）
- 全 11 単元から均等バランスで出題（毎回出題内容が変わる）
- 選択肢の並び順もランダム（位置の記憶による解答を防止）
- 問題フラグ機能・問題ナビゲーションパネル
- 採点後に全問解説・単元別正解率を表示
- **正解率 70% 以上で紙吹雪エフェクト** 🎉

### 🔢 電卓
- 全モードで常時利用可能（本番試験と同様）
- ダークデザインのニューモーフィックUI

### 📈 進捗管理
- 単元別の学習進捗・正解率
- 受験履歴（スコア・残り時間）
- localStorage によるデータ永続化

## 学習コンテンツの特徴

数学が苦手な方でも理解できるよう、以下の方針で解説を作成しています。

- **例題先・式は後から**：まず具体的な数値で手順を確認、その後で数式を提示
- **「なぜ？」の解説**：n-1 で割る理由、中央値が外れ値に強い理由なども説明
- **日常の例え話**：年収・サイコロ・気温・医療検査など身近な例を多用
- **ステップ付き計算**：計算手順を番号付きで丁寧に分解
- **key-point / example-box**：重要事項と具体例を視覚的に区別
