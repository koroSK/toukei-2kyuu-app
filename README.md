# 統計検定2級 学習アプリ

統計検定2級の取得を目指すための学習・試験対策 Web アプリです。  
全 11 単元・115 問で試験範囲を完全網羅し、初学者でも体系的に学習できます。

🔗 **公開 URL**: https://korosk.github.io/toukei-2kyuu-app/

---

## 主な機能

### 📚 学習モード
- 全 11 単元のテキスト解説（具体例・重要ポイント付き）
- KaTeX による数式レンダリング
- 単元別確認テスト（選択肢・出題順ともにランダム）
- 学習進捗・正解率の記録

### 📝 試験モード（CBT 形式）
- 本番準拠：35 問・90 分タイマー
- 全 11 単元から均等バランスで出題（毎回出題内容が変わる）
- 選択肢の並び順もランダム（位置の記憶による解答を防止）
- 問題フラグ機能・問題ナビゲーションパネル
- 採点後に全問解説・単元別正解率を表示

### 🔢 電卓
- 全モードで常時利用可能（本番試験と同様）

### 📈 進捗管理
- 単元別の学習進捗・正解率
- 受験履歴（スコア・残り時間）
- localStorage によるデータ永続化

| 8 | 分散分析（ANOVA） | 3 問 |
| 9 | 回帰分析・相関分析 | 3 問 |

├── index.html            # エントリーポイント
├── README.md             # このファイル
├── SPEC.md               # 仕様書
├── css/
│   └── style.css         # スタイル（レスポンシブ対応）
